LocalSend: Kirim File HP ke Laptop Apa Pun Gratis, Tanpa Kabel dan Tanpa Internet

12 November 2026Alternatif gratis

LocalSend adalah aplikasi gratis untuk mengirim file dari HP ke laptop, atau sebaliknya, tanpa kabel, tanpa akun, dan tanpa internet. File bergerak langsung lewat WiFi yang sama, jadi foto dan video sampai utuh. Aplikasi ini jalan di Android, iPhone, Windows, Mac, dan Linux.

Intinya begini. LocalSend adalah aplikasi berbagi file lintas platform yang gratis dan open source. Kamu pasang aplikasinya di dua perangkat, pastikan keduanya tersambung ke WiFi yang sama, pilih file, ketuk nama perangkat tujuan, dan file langsung terkirim. Tidak ada akun yang perlu dibuat dan tidak ada file yang diunggah ke server mana pun. Situs resminya menyebut LocalSend sudah diunduh lebih dari 35 juta kali dan punya lebih dari 93 ribu bintang di GitHub per November 2026. Transfernya terenkripsi lewat HTTPS, dan kamu bisa mengaktifkan verifikasi PIN supaya perangkat lain tidak bisa asal mengirim file ke kamu. Kelemahan utamanya cuma satu: kedua perangkat harus berada di jaringan lokal yang sama, jadi aplikasi ini bukan alat kirim file jarak jauh. Buat pindahan file di rumah atau kantor, itu sudah lebih dari cukup.

Kenapa AirDrop saja tidak cukup?

AirDrop enak, tapi cuma jalan di perangkat Apple. Punya iPhone dan laptop Windows, kamu langsung mentok. Quick Share dari Google juga mirip: enak di sesama Android, tapi tidak tersedia di iPhone. Jalan keluar yang paling sering dipakai orang akhirnya kirim file ke diri sendiri lewat WhatsApp atau unggah ke Google Drive, lalu unduh lagi. Cara itu jalan, tapi ada harganya: video besar antre di antrean unggah, dan file kamu mampir dulu ke server orang lain. LocalSend memotong semua jalan memutar itu. Satu aplikasi yang sama terpasang di semua perangkat, dan file pindah langsung dari perangkat ke perangkat.

Apakah LocalSend benar-benar gratis dan aman?

Ya. Situs resmi LocalSend menulis langsung: aplikasi ini 100 persen gratis dan open source, tanpa iklan, tanpa pelacak, dan tanpa biaya tersembunyi. Kodenya terbuka di bawah lisensi Apache 2.0, jadi siapa pun bisa memeriksa apa yang dilakukan aplikasi itu dengan file kamu. Soal keamanan, semua transfer berjalan lewat HTTPS dan terenkripsi, jadi hanya kamu dan penerima yang bisa membuka file itu. Ada juga opsi PIN: aktifkan di pengaturan penerima, dan setiap pengiriman harus memasukkan PIN dulu. Yang perlu kamu pahami, enkripsi ini berlaku saat kedua perangkat memakai aplikasi LocalSend. Kalau penerima membuka tautan lewat browser (mode tanpa aplikasi), transfernya lewat HTTP biasa dan tidak terenkripsi, jadi pakai mode itu hanya untuk file yang tidak sensitif.

Bagaimana cara kirim file pakai LocalSend?

Caranya cuma tiga langkah, dan tidak ada yang perlu didaftarkan.

  1. Pasang LocalSend di kedua perangkat. Unduh dari situs resminya, localsend.org, atau dari toko aplikasi masing-masing perangkat: Google Play untuk Android, App Store untuk iPhone, dan Microsoft Store untuk Windows. Versi Linux tersedia lewat Flathub dan paket AppImage. Aplikasi ini mendukung Android 7.0 ke atas dan iOS 13 ke atas.
  2. Sambungkan kedua perangkat ke WiFi yang sama. Buka LocalSend di perangkat penerima dulu, biarkan aplikasinya terbuka. Di perangkat pengirim, aplikasi akan menampilkan nama perangkat penerima secara otomatis.
  3. Pilih file, ketuk nama perangkat tujuan, lalu ketuk terima di perangkat penerima. File tersimpan di folder Downloads secara bawaan, dan kamu bisa mengubah lokasi simpan ini di pengaturan.

Kalau perangkat tujuan tidak punya aplikasi LocalSend, masih ada jalan: di tab Kirim ada pilihan berbagi lewat tautan. LocalSend akan menampilkan alamat web lokal di port 53317, dan penerima cukup membukanya di browser lalu mengunduh file itu. Praktis buat kirim file ke laptop teman yang tidak mau pasang aplikasi baru.

Kapan LocalSend tidak bisa dipakai?

Batas terbesarnya adalah jaringan. Kedua perangkat harus berada di WiFi yang sama. Satu perangkat di data seluler dan satu lagi di WiFi, transfer tidak jalan. WiFi tamu di kantor atau kafe juga sering memblokir perangkat untuk saling melihat, begitu juga VPN yang sedang aktif. Kalau perangkat penerima tidak muncul di daftar, coba tiga hal ini: pastikan keduanya di WiFi yang sama, matikan VPN sementara, dan periksa izin jaringan di firewall laptop kamu. Hotspot dari HP bisa jadi jalan darurat: sambungkan kedua perangkat ke hotspot yang sama, dan LocalSend biasanya langsung menemukan perangkatnya. Satu lagi: LocalSend bukan pengganti cloud. File tidak bisa dikirim ke orang di kota lain, karena memang tidak ada server perantara. Untuk itu, tetap pakai Google Drive atau layanan sejenis.

LocalSend, AirDrop, atau Google Drive?

Pakai AirDrop kalau semua perangkat kamu Apple, karena sudah terpasang dan tidak perlu aplikasi tambahan. Pakai Quick Share kalau sesama Android dan laptop kamu sudah mendukungnya. Pakai Google Drive kalau file harus sampai ke orang di tempat lain, atau kamu butuh cadangan yang bisa dibuka kapan saja. Pakai LocalSend untuk semua situasi di antaranya: iPhone ke laptop Windows, Android ke Mac, atau laptop ke laptop beda sistem di ruangan yang sama. Keunggulannya dibanding Drive adalah kecepatan dan privasi: file tidak naik ke internet dulu, jadi transfer video besar tidak tergantung kecepatan unggah internet kamu, dan tidak ada salinan file yang tertinggal di server mana pun. Kekurangannya, lagi-lagi, cuma soal jarak: begitu perangkat beda jaringan, LocalSend tidak bisa membantu.

Kalau kamu sering pindah file antara HP dan laptop yang beda merek, LocalSend pantas dipasang di semua perangkat kamu. Gratis, tanpa akun, dan sekali pasang, cara kirim file yang dulu ribet jadi semudah ketuk nama perangkat. Unduh dari localsend.org, coba kirim satu foto dulu, dan rasakan sendiri bedanya.
