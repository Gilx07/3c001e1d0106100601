Cara Menggabungkan PDF Jadi Satu File Gratis di HP dan Laptop

9 November 2026Tutorial evergreen

Kamu bisa menggabungkan beberapa PDF jadi satu file gratis tanpa install aplikasi, lewat situs iLovePDF atau Smallpdf di browser HP dan laptop. Buka situsnya, unggah semua file PDF, atur urutannya, lalu klik gabungkan dan unduh hasilnya. Kalau dokumennya rahasia, pakai aplikasi offline PDFsam Basic supaya berkas tidak diunggah ke server mana pun.

Cara tercepatnya lewat iLovePDF di browser. Buka ilovepdf.com/merge_pdf, pilih semua file PDF yang mau digabung, seret untuk mengatur urutan, lalu tekan tombol Merge PDF dan unduh satu file hasilnya. Cara ini gratis, tidak perlu daftar, dan jalan di HP Android, iPhone, maupun laptop. Smallpdf punya cara yang sama di smallpdf.com/merge-pdf, bedanya kamu juga bisa mencampur file Word, Excel, dan gambar JPG ke dalam satu PDF. Kalau dokumenmu berisi data sensitif seperti KTP, slip gaji, atau kontrak, jangan pakai situs online. Unduh PDFsam Basic dari pdfsam.org, aplikasi gratis dan open source yang bekerja sepenuhnya offline di Windows, macOS, dan Linux, tanpa watermark dan tanpa batas ukuran file. Pengguna iPhone punya jalan pintas bawaan: pilih beberapa PDF di aplikasi Files, ketuk menu, lalu pilih Create PDF. Per November 2026, ketiga cara di atas masih gratis untuk kebutuhan biasa.

Bagaimana cara menggabungkan PDF di HP dan laptop tanpa install aplikasi?

Pakai iLovePDF kalau kamu mau cara yang paling cepat. Buka browser di HP atau laptop, lalu kunjungi ilovepdf.com/merge_pdf. Ketuk tombol Select PDF files dan pilih semua file yang mau digabung. Kamu bisa memilih beberapa file sekaligus, atau menambahkannya satu per satu. Sesudah semua file terunggah, seret tiap file untuk mengatur urutannya. Urutan di layar adalah urutan halaman di hasil akhir, jadi periksa sekali lagi sebelum lanjut. Kalau sudah yakin, tekan tombol Merge PDF di pojok kanan bawah dan tunggu sebentar. Hasilnya langsung bisa diunduh sebagai satu file PDF. Situs ini gratis dan tidak meminta kamu membuat akun. Satu hal yang perlu diingat, file PDF yang terkunci kata sandi tidak bisa digabung di sini. Buka dulu kunci file itu sebelum diunggah. Cara ini cocok untuk tugas kuliah, berkas lamaran, dan dokumen kerja yang tidak sensitif.

Kapan sebaiknya gabung PDF secara offline?

Kalau dokumenmu rahasia, jangan diunggah ke situs mana pun. Pakai PDFsam Basic, aplikasi gratis dan open source yang bekerja sepenuhnya di komputermu sendiri. Unduh aplikasinya dari pdfsam.org, tersedia untuk Windows, macOS, dan Linux. Sesudah terpasang, buka modul Merge, tambahkan file PDF yang mau digabung, lalu atur urutannya di tabel. Kamu juga bisa memilih halaman tertentu saja dari tiap file, misalnya hanya halaman 1 sampai 3. Tentukan folder tujuan dan nama file hasil, lalu klik Run. Karena semua proses berjalan lokal, berkasmu tidak pernah keluar dari laptop dan tidak butuh internet sama sekali. PDFsam Basic juga tidak memberi watermark dan tidak membatasi ukuran file, menurut halaman resminya. Kekurangannya cuma satu, kamu harus install dulu dan cara ini hanya jalan di laptop, bukan di HP.

Bagaimana kalau file yang digabung bukan semuanya PDF?

Smallpdf cocok kalau bahanmu campur aduk. Buka smallpdf.com/merge-pdf, unggah file PDF, Word, Excel, atau gambar JPG dan PNG sekaligus. Atur urutan lewat gambar kecil tiap halaman, hapus halaman yang tidak perlu, lalu klik Gabungkan PDF dan unduh hasilnya. Smallpdf mengenkripsi file saat diunggah dan menghapusnya dari server sesudah satu jam, menurut halaman resminya. Paket gratisnya punya batasan pemakaian harian, jadi cara ini paling pas untuk kebutuhan sesekali, bukan gabung PDF tiap jam. Pengguna iPhone punya jalan pintas tanpa situs apa pun. Buka aplikasi Files, pilih beberapa file PDF, ketuk menu titik tiga, lalu pilih Create PDF. iPhone langsung menggabungkan file itu jadi satu PDF baru tanpa install aplikasi tambahan. Jalan ini paling praktis kalau semua berkasmu sudah tersimpan di iPhone.

Dokumen apa yang sebaiknya tidak digabung lewat situs online?

Jangan unggah dokumen berisi KTP, paspor, slip gaji, rekening koran, kontrak, atau ijazah ke situs gabung PDF mana pun, termasuk situs yang terlihat meyakinkan. Sekali diunggah, kamu tidak bisa memastikan salinannya benar-benar terhapus dari server. Pakai PDFsam Basic untuk dokumen seperti itu. Sebaliknya, tugas kuliah, materi presentasi, dan berkas lamaran umum aman-aman saja digabung online. Satu mitos yang perlu diluruskan, Google Drive tidak punya fitur gabung PDF bawaan. Smallpdf sendiri menulis di halamannya bahwa Drive tidak punya fungsi itu, dan yang bisa kamu lakukan hanyalah memakai alat Smallpdf lalu menyimpan hasilnya ke Drive. Jadi kalau ada panduan yang menyuruhmu menggabungkan PDF langsung di Google Drive, panduan itu keliru.

Intinya, pilih cara sesuai dokumenmu. Butuh cepat, pakai iLovePDF. Dokumen rahasia, pakai PDFsam Basic. Bahan campur format, pakai Smallpdf. Sekali kamu hafal langkahnya, menggabungkan beberapa PDF terasa seperti pekerjaan ringan.

Sumber dan Info Resmi

Angka, harga, dan batas gratis di artikel ini merujuk ke sumber berikut:

  • iLovePDF: gabung PDF gratis lewat browser, tombol Select PDF files dan Merge PDF, atur urutan dengan drag and drop, file PDF terkunci kata sandi tidak bisa digabung.
  • Smallpdf: gabung PDF gratis tanpa install, file dienkripsi saat diunggah dan dihapus dari server sesudah satu jam, bisa mencampur file Word, Excel, JPG, dan PNG, Google Drive tidak punya fitur gabung PDF bawaan.
  • PDFsam Basic: gratis dan open source sejak 2006, tanpa watermark, tanpa batas ukuran file, bekerja sepenuhnya offline di Windows, macOS, dan Linux.
  • PDFsam FAQ: PDFsam Basic gratis sepenuhnya, open source di bawah lisensi AGPL, butuh sistem 64-bit dan sekitar 70 MB ruang disk.
  • Viralnih dan Wigatos: paket gratis Smallpdf dibatasi pemakaian harian.
